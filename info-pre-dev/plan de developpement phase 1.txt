### Structure de projet VS Code pour le site vitrine

```
TATBooker-Website/               # Site vitrine uniquement
├── index.html                   # Page principale
├── favicon.ico                  # Icône navigateur
├── robots.txt                   # SEO
├── sitemap.xml                  # SEO
│
├── css/
│   ├── style.css                # Styles généraux
│   ├── palettes.css             # Définition des 5 palettes (Soleil, Pluie, Nuit, Tempête, Harmattan)
│   ├── glassmorphism.css        # Composants glass card
│   └── responsive.css           # Media queries mobile/tablette
│
├── js/
│   ├── main.js                  # Point d'entrée JavaScript
│   ├── palette-engine.js        # Moteur d'oscillation des couleurs
│   ├── palette-selector.js      # Sélecteur manuel (5 boutons)
│   ├── weather-simulator.js     # Simulation météo (pour démo)
│   ├── contact-form.js          # Gestion formulaire de contact
│   ├── lead-capture.js          # Envoi leads vers Google Sheets/Supabase
│   └── analytics.js             # Événements + Google Analytics
│
├── assets/
│   ├── images/
│   │   ├── hero-bg.jpg          # Image de fond principale
│   │   ├── logo.svg             # Logo TATBooker
│   │   └── favicon/             # Icônes multiples
│   ├── fonts/
│   │   └── inter/               # Police Inter (Google Fonts fallback)
│   └── icons/                   # Icônes SVG
│
├── services/                    # Services externes (JS uniquement)
│   ├── supabase-client.js       # Connexion Supabase pour leads
│   └── email-service.js         # Envoi email de confirmation
│
├── data/                        # Données statiques
│   └── testimonials.json        # Témoignages clients
│
└── scripts/                     # Utilitaires de déploiement
    ├── deploy-netlify.sh        # Script déploiement Netlify
    └── deploy-github-pages.sh   # Script déploiement GitHub Pages
```

### Plan de développement par sprint (site vitrine)

#### Sprint 3 : Capture de leads (Jour 5-6)

```markdown

- [ ] Implémenter `js/lead-capture.js`

```

#### Sprint 4 : Analytics et déploiement (Jour 7)

```markdown
- [ ] Ajouter Google Analytics (tracking pages vues, clics)

- [ ] Tester sur mobile, tablette, desktop
```
