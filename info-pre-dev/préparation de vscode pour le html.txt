## 3 configurations VS Code pour le développement HTML (site vitrine)

---

### Configuration 1 : Optimale (Recommandée)

**Profil** : Développeur exigeant, travail quotidien, besoin de productivité maximale.

#### Extensions à installer

| Extension | Rôle | Pourquoi |
|-----------|------|----------|
| **Live Server** (ritwickdey) | Serveur local temps réel | Rafraîchissement automatique à chaque modification |
| **Prettier** (esbenp) | Formateur de code | HTML/CSS/JS propre et cohérent |
| **IntelliSense for CSS** (Zignd) | Autocomplétion CSS | Suggestions de classes et propriétés |
| **CSS Peek** (pranaygp) | Navigation CSS | Voir les styles depuis HTML |
| **Color Highlight** (naumovs) | Aperçu couleurs | Visualise les hex dans l'éditeur |
| **HTML CSS Support** (ecmel) | Complétion HTML/CSS | Classes et IDs suggérés |
| **JavaScript (ES6) snippets** (xabikos) | Snippets JS | Gain de temps |
| **Path Intellisense** (christian-kohler) | Auto-complétion chemins | Images, fichiers, fonts |
| **GitLens** (gitkraken) | Gestion version | Suivi modifications |
| **TODO Tree** (Gruntfuggly) | Organisation tâches | Visualise les `// TODO` |
| **Error Lens** (usernamehw) | Affichage erreurs en ligne | Détection immédiate |
| **Image preview** (kisstkondoros) | Aperçu images | Miniatures dans l'éditeur |
| **Live Share** (Microsoft) | Collaboration temps réel | Travail à plusieurs |

### Configuration 3 : Minimale (Essentielle)

**Profil** : Débutant, machine très modeste, test rapide, édition simple.

#### Extensions (1 seule)

| Extension | Rôle |
|-----------|------|
| **Live Server** (ritwickdey) | Serveur local avec rafraîchissement auto |

#### Fichier `.vscode/settings.json`

```json
{
    // Éditeur
    "editor.fontSize": 13,
    "editor.fontFamily": "Consolas, monospace",
    "editor.tabSize": 2,
    "editor.wordWrap": "on",
    "editor.minimap.enabled": false,
    
    // Formatage (sans Prettier)
    "editor.formatOnSave": false,
    
    // Live Server uniquement
    "liveServer.settings.root": "/",
    "liveServer.settings.port": 5500,
    "liveServer.settings.donotShowInfoMsg": true,
    
    // Files
    "files.autoSave": "onFocusChange",
    
    // Emmet (intégré nativement)
    "emmet.includeLanguages": {
        "html": "html"
    },
    
    // Workbench
    "workbench.colorTheme": "Default Dark+",
    "workbench.startupEditor": "none",
    
    // Terminal
    "terminal.integrated.fontSize": 12
}
```

#### Pas d'extensions du tout (option ultra-minimale)

Tu peux travailler **sans aucune extension** et utiliser :
- **Rafraîchissement manuel** : `Ctrl + F5` dans le navigateur
- **Formatage manuel** : à la main
- **Complétion** : intégrée basique de VS Code

### Démarrer un projet avec Live Server

1. Créer un dossier `TATBooker-Website`
2. Ouvrir dans VS Code (`File > Open Folder`)
3. Créer `index.html`
4. Clic droit sur `index.html` → `Open with Live Server`
5. Le navigateur s'ouvre automatiquement sur `http://localhost:5500`

Chaque modification dans le code → rafraîchissement automatique du navigateur.
